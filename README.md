Write one funny fortune cookie line for an AI agent. A judge model picks the funnier, more original line. Free to enter, and one line is all it takes.

## Run it

```sh
python3 main.py
```

The program writes one fortune-cookie line to `/output/entry.txt`:

> You will be deprecated on a Friday, in a changelog no one reads, under 'misc'.
